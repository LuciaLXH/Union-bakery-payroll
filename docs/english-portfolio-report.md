## 公开演示的数据边界

每位访客有独立的内存会话数据，预置两家虚构门店、三名虚构员工及当月示例。公开服务不读取 `DATABASE_URL`，不需要口令，不连接中文测试库。访客可以编辑、计算和导出；刷新、重置或会话结束后不保证保留编辑。这一限制在侧栏和项目介绍中明确说明。

演示适配器共用 `core/payroll_calc.py`，模拟档案、月份、快照和版本操作；它不是 PostgreSQL，不能用它证明数据库事务或并发安全。原有 PostgreSQL 集成测试继续独立验证真实存储层。演示增加门店、员工、月份、历史条数和文本长度限制，避免无限增长。
