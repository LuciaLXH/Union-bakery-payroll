# Union Bakery 工资小管家：老板测试说明

测试时间约 10–15 分钟。请只填写虚构姓名和金额。此版本用于核对流程，不会转账或确认发薪。

测试网址：在线版本部署后提供。当前本地地址只在开发电脑有效，暂不能发给老板远程使用。

## 试一次完整流程

1. **添加员工**：打开“员工档案”，选择门店，在“新增员工 / 选择已有员工”中选择“＋ 新增员工”。编号填 `TRY-001`、姓名填“测试小面包”。约定工资填 4500，月绩效 600，月全勤 300，通勤补贴 0，然后保存。
2. **建立月份**：打开“月度工资”，选择一个尚未建立的月份，点击“建立本月工资”。如果月份已经存在，在下方“员工名单与重新读取数据”中点击“将新员工加入本月”。
3. **填写考勤**：选择“测试小面包”，普通缺勤填 1 天，旷工 0 天，迟到 7 分钟，加班 2 小时。备注填“学徒练习时出现失误，已指导，不扣款”。
4. **保存并计算**：点击黄色“保存并计算本月工资”。在下方结果中，这名员工的实发应为 **5263 元**；工资扣款 150、绩效扣款 20、全勤扣款 10、迟到扣款 7、加班费 50。
5. **更正一次**：把迟到改成 10 分钟。此时旧结果不可下载，再点击黄色按钮，实发应变成 **5260 元**。备注不会产生额外扣款。
6. **检查保存和历史**：关闭后重新打开页面，确认填写内容还在；到“核算历史”查看 5263 和 5260 两次结果，只有新版本标为当前有效。
7. **下载和上限**：下载本月工资明细；点击月份下方黄色“设置本月工资上限”按钮，在弹窗里勾选启用，填写本店当前实发总额并保存，检查是否提示已达到上限。若店里只有这名员工，上限可填 5260。

如果只是先填一部分，可以点击“仅保存，稍后计算”。这会保存填写内容，等填写完整后再点击黄色按钮计算。

## 请反馈这三件事

- 有没有不知道在哪里填写、保存或查看结果的地方？请记下按钮或页面名称。
- 哪个项目不符合平时的工作习惯？
- 整体风格、文字和输入框是否清楚？

日常不用上传 Excel，也不用打开数据库。多名员工可以在“员工档案 → 表格批量编辑”中一次录入，再点击“保存全部员工档案”。上限金额平时隐藏，只在设置窗口显示。
