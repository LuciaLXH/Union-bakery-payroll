# Union Bakery 工资小管家：老板测试说明

测试时间约 10–15 分钟。请只填写虚构姓名和金额。此版本用于核对流程，不会转账或确认发薪。

测试网址：https://union-bakery-payroll-test.onrender.com

用电脑浏览器打开，输入单独提供的测试口令即可，不用安装 Python、数据库或其他软件。免费服务闲置后会休眠，再次打开通常需要等待约一分钟；登录后再开始操作。刷新或重新打开页面可能需要再次输入口令，已保存数据不会丢失。

已有“Union 虚构测试店”和“示例小面包”供查看。下面请新增另一名虚构员工，以体验完整流程。

## 试一次完整流程

1. **添加员工**：打开“员工档案”，选择门店，在“新增员工 / 选择已有员工”中选择“＋ 新增员工”。编号填 `TRY-001`、姓名填“测试小面包”。约定工资填 4500，月绩效 600，月全勤 300，通勤补贴 0，然后保存。
2. **建立月份**：打开“月度工资”，选择一个尚未建立的月份，点击“建立本月工资”。如果月份已经存在，在下方“员工名单与重新读取数据”中点击“将新员工加入本月”。
3. **填写考勤**：先切换为“手动填写”，再选择“测试小面包”，普通缺勤填 1 天，旷工 0 天，迟到 7 分钟，加班 2 小时。备注填“学徒练习时出现失误，已指导，不扣款”。
4. **保存并计算**：点击黄色“保存并计算本月工资”。在下方结果中，这名员工的实发应为 **5263 元**；工资扣款 150、绩效扣款 20、全勤扣款 10、迟到扣款 7、加班费 50。
5. **更正一次**：把迟到改成 10 分钟。此时旧结果不可下载，再点击黄色按钮，实发应变成 **5260 元**。备注不会产生额外扣款。
6. **检查保存和历史**：关闭后重新打开页面，确认填写内容还在；到“核算历史”查看 5263 和 5260 两次结果，只有新版本标为当前有效。
7. **下载和上限**：下载本月工资明细；点击工资汇总旁的“设置本月工资上限”按钮，在弹窗里勾选启用，填写本店当前实发总额并保存，检查是否提示已达到上限。请按页面显示的全店实发合计填写，不要只填写某一名员工的金额。

如果只是先填一部分，可以点击“仅保存，稍后计算”。这会保存填写内容，等填写完整后再点击黄色按钮计算。

## 请反馈这三件事

- 有没有不知道在哪里填写、保存或查看结果的地方？请记下按钮或页面名称。
- 哪个项目不符合平时的工作习惯？
- 整体风格、文字和输入框是否清楚？

日常不用上传 Excel，也不用打开数据库。多名员工可以在“员工档案 → 表格批量编辑”中一次录入，再点击“保存全部员工档案”。上限金额平时隐藏，只在设置窗口显示。

## AI 随时记录（默认新增）

在“月度工资”选择月份，默认使用 AI 识别，无需先选择门店。

1. 粘贴本次新发生的事项，建议包含日期，例如“杨新宁10月8日迟到20分钟，小面包10月8日请假1天”。可以一次输入不同门店员工的记录。
2. 点击“整理记录”，核对员工、事项、数量和处理方式。不正确时直接修改表格；员工不明确时按姓名和门店选择。
3. 查看自动展示的工资影响、预计实发和计算门店。备注只保留文字，报损目前不扣款。
4. 点击“确认以上记录并计算工资”，一次完成保存和相关门店全部当月员工的工资计算。看到成功提示后，下方可查看结果和下载 Excel，无需再计算一次。

暂不计算时，点击“先保存，稍后计算”。系统明确提示“已保存，尚未计算”；以后在下方选择门店，点击“保存并计算本月工资”。不采用这批记录时点击“取消本批记录”，不会删除已经保存的数据。

成功后核对表保留且不可重复提交；下一批修改原文，再点击“整理记录”。保存和计算不会确认锁定工资或发薪。多个门店一起计算时，任何一个失败都会撤销本批操作，修正后重新核对。

**新增与累计的区别：**

- 默认是新增：已保存迟到2分钟，再录入“迟到20分钟”，保存后为22分钟。即使写“这个月迟到20分钟”，没有明确说明总数，也按新增处理。
- 要替换本月总数，请写“本月累计迟到20分钟”或“本月总共迟到20分钟”，或在核对表选择“累计”；保存后为20分钟。
- 更正月度数据时，例如把缺勤3天改成1天，请写“更正为本月累计缺勤1天”，不要再次新增1天。
- 确认前请检查处理方式。记录错误或不确定时，可以在核对表修改。

**同一事项只录一次。** 推荐每次写明日期，只粘贴尚未录入的新事项，不要反复提交整段旧记录。系统能拦截完全相同的事项，但改写句子仍可能重复计入；同一个人在不同日期发生相同事项，必须写出各自日期。当前没有自动撤销已保存事项的功能，更正时应核对本月累计值。

页面刷新时请等待完成再继续点击。AI 核对记录不代表已发薪，也不会转账。报废事项目前只保存备注。
