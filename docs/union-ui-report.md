## 在线部署准备与边界

已准备 `render.yaml` 与 `scripts/run_cloud.sh`。配置以单个免费测试 Web 服务为目标，关闭自动部署，不在仓库里保存连接密码，不自动创建云数据库或执行建表脚本。数据库与口令哈希需要在云端填写。

配置参考 [Render Blueprint 官方说明](https://render.com/docs/blueprint-spec)。尚未通过 Render 平台实际部署验证，配置文件存在不代表资源已创建。

新增仅供虚构数据测试的共享口令入口：PBKDF2-SHA256 哈希、服务进程内错误尝试限制、四小时会话、退出清理及哈希轮换后会话失效。Render 环境与 online-test 模式都在读取业务数据前验证访问；缺失或无效口令配置时拒绝进入，云端启动脚本也会退出。

生成哈希的交互命令：

```sh
.venv/bin/python -m scripts.create_test_password
```

用户在终端自行输入口令，输入不回显；输出哈希用于云端 `TEST_PASSWORD_HASH`，原始口令不应进入代码或聊天。实际云端口令尚未设置。

这不是正式用户身份系统：测试者共用口令，没有按人员或门店授权；限速仅在单进程内，重启后重置；Streamlit 的媒体下载链接也不由此页面登录门禁单独鉴权。只使用虚构数据。正式工资环境应另做身份权限、完整下载访问控制、备份恢复和发薪锁定。

当前发布阻塞：本轮会话没有可用 Render/Neon 接口；GitHub CLI 已重新验证，认证可用。没有上传代码、迁移本地数据或建立线上网址。后续需恢复云账号连接、确认可发布的代码来源，在独立测试库应用现有结构并录入虚构数据，设置访问口令后部署和验收。
